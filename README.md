# Gerador de QR Code

Uma aplicação que permite gerar códigos QR Code a partir de um texto ou endereço informado pelo usuário.

## Funcionalidades

- Campo para inserir texto ou link
- Geração do QR Code
- Exibição do código gerado
- Interface simples e interativa

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript

## Desenvolvimento

Projeto desenvolvido individualmente, com orientação e apoio do professor.
